# 출입국 행정사 사무실 AI 직원 — F-4 재외동포

행정사 사무실의 F-4 담당 직원처럼 **상담 메모 → 유형 판별 → 요건 판정 → 서류·제출처·기한 → 보고서**를
처리하는 AI 에이전트입니다. 추측하지 않고, **검증된 지식베이스에 있는 사실만** 근거 ID와 함께 말합니다.

## 구조
```
CLAUDE.md                 에이전트 업무 지침 (역할·합리성 원칙·처리 절차)
knowledge/
  00_출처목록.md          공식 출처와 우선순위
  F-4/README.md           지식 항목 작성·검증 규칙
  F-4/요건_서류.md        요건·서류·기한 항목 (현재 전부 미검증 초안)
  원문/                   매뉴얼 PDF 원문 보관 (직접 추가)
templates/                상담접수표, 업무보고서 양식
.claude/commands/         /consult (손님 상담), /f4 (사건 처리), /verify (지식 검증)
tests/시나리오.md         에이전트 행동 점검 사례
cases/                    실제 사건 파일 — git에 올라가지 않음 (개인정보)
```

## 사용법 (Claude Code)
1. 이 폴더에서 `claude` 실행
2. 손님 상담: `/consult` 입력 후 손님 역할로 대화 (끝나면 접수표 정리)
3. 사건 처리: `/f4 미국 시민권자 64세 남성, 무비자 입국 ...`
4. 지식 검증: 매뉴얼 PDF를 `knowledge/원문/` 에 넣고 `/verify F4-EXEMPT-01`

Claude 웹 "프로젝트"에서 쓰려면 `CLAUDE.md` 내용을 프로젝트 지침에, `knowledge/` 파일들을 프로젝트 지식에 올리면 됩니다.

## 시작 전 꼭 할 일
1. 하이코리아에서 최신 「체류민원 자격별 안내 매뉴얼」을 받아 `knowledge/원문/` 에 저장
2. `/verify all` 로 `요건_서류.md` 항목을 원문과 대조해 `검증됨` 으로 전환
3. `tests/시나리오.md` 다섯 사례로 에이전트 행동 점검

검증 전에는 에이전트가 모든 답에 ⚠ 표시를 붙입니다. 정상 동작입니다.

## 주의
- 에이전트 출력은 직원 보고서(초안)입니다. 최종 판단과 제출 책임은 행정사에게 있습니다.
- 실제 의뢰인 정보는 `cases/` 에만 두세요. GitHub에 올라가지 않습니다.
