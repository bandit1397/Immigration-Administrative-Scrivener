# F-4 지식베이스 작성 규칙

에이전트는 이 폴더의 **`상태: 검증됨`** 항목만 사실로 말합니다. 정확도는 이 폴더의 품질로 결정됩니다.

## 항목 형식
```
### F4-<분류>-<번호> 제목
- 내용: (한 가지 사실만. 조건이 있으면 조건까지)
- 적용 유형: A / B / C / D
- 출처: 문서명, 판(발행일), 페이지 또는 URL
- 확인일: YYYY-MM-DD
- 상태: 미검증 | 검증됨 | 폐지
- 비고:
```

분류 코드: `ELIG`(자격·동포 입증) · `DOC`(서류) · `EXEMPT`(면제) · `DEADLINE`(기한) · `FEE`(수수료) · `PENALTY`(과태료) · `WORK`(취업제한) · `PROC`(접수 절차·관할)

## 검증 절차
1. 공식 출처(`../00_출처목록.md`)에서 원문을 찾는다.
2. 원문과 내용이 일치하면 출처·페이지·확인일을 적고 `상태: 검증됨` 으로 바꾼다.
3. 다르면 내용을 원문대로 고치고 비고에 변경 전 내용을 남긴다.
4. 지침 개정으로 효력이 없어지면 삭제하지 말고 `상태: 폐지` 로 둔다.

원문 PDF는 `knowledge/원문/` 에 넣어두면 에이전트가 직접 대조할 수 있습니다.
