---
description: 지식베이스 항목을 공식 원문과 대조해 검증한다
argument-hint: <항목 ID 또는 "all"> [원문 파일 경로]
---
지식베이스 항목 `$ARGUMENTS` 를 검증하라.

1. `knowledge/원문/` 의 원문(PDF·텍스트) 또는 사용자가 지정한 공식 출처에서 해당 내용을 찾는다.
   원문이 없으면 어떤 공식 문서의 어느 부분을 받아야 하는지 알려주고 멈춘다.
2. 항목 내용과 원문을 나란히 인용해 비교표를 보여준다 (원문 페이지 표기).
3. 일치/불일치/원문에 없음 중 하나로 판정한다.
4. 사용자가 승인하면 그때 항목의 내용·출처·확인일·상태를 수정한다. 승인 없이 `검증됨` 으로 바꾸지 않는다.
